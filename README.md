# Modern Blog Platform

A responsive and interactive blog platform built using HTML, CSS, and JavaScript.

## Features
- Create blog posts
- Delete blog posts
- Like functionality
- Comment section
- Local storage support
- Responsive modern UI
- Date & time display

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Preview
This project allows users to publish blogs, interact through comments, and manage posts with a modern responsive interface.
